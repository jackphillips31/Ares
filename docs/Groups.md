@defgroup multithreading Multi-Threading
@brief Systems and utilities for concurrent execution.
@details The multi-threading module provides tools for managing parallel exection
in the engine. It includes a thread pool, synchronization primitives,
and job scheduling mechanisms to optimize performance and responsiveness.

@defgroup aliases Type Aliases
@brief Common typedefs and aliases for standard containers.
@details The Alias module provides convenient type definitions for frequently used
container types such as vectors, hash maps, and sets. This helps maintain consistency
across the engine and allows for easy adjustments to underlying implementations
if needed.
