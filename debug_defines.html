Macros for debugging, assertions, and error checking.

This group contains macros designed to assist with debugging and error detection during development. Common features include assertion checks, debug logging, and diagnostic outputs. These macros help ensure code correctness and simplify the debugging process by providing clear runtime feedback on issues.

Typical macros in this group include conditional logging (e.g., only in debug builds) and assertions that trigger when certain conditions fail.

AR_BUILD_DEBUG

◆ AR_BUILD_DEBUG

#define AR_BUILD_DEBUG    1
Defined with a value of 1 if the build is in debug mode.

This macro is used to enable or disable certain debug-specific features, such as assertions and profiling.

AR_ENABLE_ASSERTS

◆ AR_ENABLE_ASSERTS

#define AR_ENABLE_ASSERTS    1
Defined with a value of 1 to enable assertions in debug mode.

This macro's value is set to 1 when AR_BUILD_DEBUG is set.

AR_ENABLE_PROFILING

◆ AR_ENABLE_PROFILING

#define AR_ENABLE_PROFILING    1

This macro's value is set to 1 when profiling should be enabled in debug builds.
